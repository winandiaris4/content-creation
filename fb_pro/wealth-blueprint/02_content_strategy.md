# 02. Content Strategy — Wealth Blueprint

Dokumen ini menguraikan pilar konten, arsitektur format video (Reels vs In-Stream), serta formula struktur konten dengan retensi tinggi (*high-retention framework*).

---

## 1. Analisis Ekosistem Algoritma Facebook

Berdasarkan data performa organik Meta:
* **Post Statis (Foto & Teks):** Rata-rata organic reach hanya **1.37%** dengan engagement median 0.2%. Format ini sudah tidak efektif untuk pertumbuhan organik.
* **Facebook Reels:** Memberikan **2.5x hingga 3x organic reach** dibandingkan post konvensional karena Meta agresif mensubsidi distribusi video pendek untuk bersaing dengan TikTok.
* **Kebijakan Konten Orisinal:** Meta memberikan penalti berat bagi reposting (*Limited Originality of Content*). Konten animasi orisinal Wealth Blueprint berada pada posisi yang sangat aman dan disukai algoritma.

---

## 2. Strategi Dua Jalur (*Dual-Track Format Strategy*)

Wealth Blueprint beroperasi menggunakan dua format utama dengan fungsi komplementer:

```
┌─────────────────────────────────┐      ┌─────────────────────────────────┐
│     TRACK A: Facebook Reels     │      │   TRACK B: In-Stream Video      │
│          (30–60 detik)          │      │         (3–5+ menit)            │
├─────────────────────────────────┤      ├─────────────────────────────────┤
│ • Top-of-Funnel (Pertumbuhan)   │ ───► │ • Akumulasi Menit Tonton (600K) │
│ • Disubsidi algoritma Meta      │      │ • Memenuhi syarat In-Stream Ads │
│ • Tarik followers baru          │      │ • Membangun kedalaman & trust   │
└─────────────────────────────────┘      └─────────────────────────────────┘
```

## 4. Formula Konten Retensi Tinggi (*High-Retention Blueprint*)

Setiap video harus mengikuti alur psikologis 4 tahap:

```
[00:00 - 00:03] Hook Agresif
   ↓
[00:03 - 00:15] Konflik / Agitasi Masalah (Pain Point)
   ↓
[00:15 - 00:45] Blueprint / Solusi Framework Buku
   ↓
[00:45 - 01:00] "So What" Takeaway + Call To Action (CTA)
```

### Standar Hook:
* ❌ *Generic Hook:* "Here is how compound interest works."
* ✅ *High-Retention Hook:* "Most Americans lose $500,000 in retirement because of THIS one mistake — and it takes 10 minutes to fix."
